# Python Codewars Tasks

## О проекте
В этом проекте собраны мои решения задач Codewars на языке Python.

Каждое задание сохранено в отдельном Python-файле.

## Структура проекта
Файлы заданий имеют следующую нумерацию:
- 01_task.py
- 02_task.py
- 03_task.py
- и далее по порядку.

## Язык программирования
Python
