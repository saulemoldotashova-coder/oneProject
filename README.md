##  Python Codewars Tasks

## О проекте
В этом проекте собраны мои решения задач Codewars на языке Python.
Каждое выполненное задание сохранено в отдельном Python-файле.

## Структура проекта
Все задания находятся в папке for_module.
Файлы имеют последовательную нумерацию от 01_task.py до 15_task.py.

## Список выполненных заданий

| № | Название задания | Функция | Описание |
|---|---|---|---|
| 01 | List Filtering | `filter_list()` | Оставляет в списке только целые числа |
| 02 | Stop gninnipS My sdroW! | `spin_words()` | Переворачивает слова из пяти и более букв |
| 03 | String ends with? | `solution()` | Проверяет, заканчивается ли строка заданным окончанием |
| 04 | Does my number look big in this? | `narcissistic()` | Проверяет, является ли число нарциссическим |
| 05 | Unique In Order | `unique_in_order()` | Удаляет повторяющиеся соседние элементы |
| 06 | Friend or Foe? | `friend()` | Оставляет имена длиной ровно четыре символа |
| 07 | Is a number prime? | `is_prime()` | Проверяет, является ли число простым |
| 08 | Bouncing Ball | `bouncing_ball()` | Подсчитывает количество видимых наблюдений мяча |
| 09 | Delete occurrences | `delete_nth()` | Ограничивает количество повторений элементов |
| 10 | Count characters in your string | `count()` | Подсчитывает количество каждого символа |
| 11 | Split Strings | `solution()` | Разделяет строку на пары символов |
| 12 | Roman Numerals Encoder | `solution()` | Преобразует число в римскую запись |
| 13 | Count IP Addresses | `ips_between()` | Считает количество IP-адресов между двумя адресами |
| 14 | First non-repeating letter | `first_non_repeating_letter()` | Находит первый неповторяющийся символ |
| 15 | Directions Reduction | `dir_reduc()` | Сокращает последовательность противоположных направлений |
